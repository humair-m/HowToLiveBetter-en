اس دور کے set rule "قانونی support کے بارے میں لکھتے ہوئے process cost بھی لکھیں" کے مطابق، Note بیان کرتا ہے: platform سب سے تیز اور سب سے سستا ہے، court سب سے slow اور سب سے مہنگا ہے، اس لیے پہلے ثبوت preserve کریں اور پہلے report کریں؛ injunction کے لیے court کو apply کرنا ضروری ہے، private prosecution کے لیے victim کا خود case file اور prove کرنا ضروری ہے، اور public prosecution میں conversion کے لیے Item 12 کی پانچ میں سے ایک circumstance پوری کرنا ضروری ہے؛ انہیں پورا نہ کرنے کی صورت میں صرف private prosecution باقی ہے۔ دو اضافی "نہ کریں": mutual insults میں engage نہ کریں (جو آپ کو اندراج 14 کے تحت punish شدہ شخص بنائے گا)، اور اپنے account سے content delete نہ کریں (یہ ثبوت ہے)۔
