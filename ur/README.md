## کیسے پڑھیں

- **AI سے تلاش کروانا چاہتے ہیں**: ریپو میں ایک چینی سکل ([skills/life-decision-guide](skills/life-decision-guide/)) شامل ہے جو Claude Code اور Codex دونوں کے ساتھ کام کرتی ہے۔ انسٹال کرنے کے بعد، "کیا میں دوست کے لیے ضامن بنوں؟" یا "کیا روزانہ دو گھنٹے کا کمیوٹ قابل ہے؟" پوچھیں۔ یہ پہلے مرکزی متن سے متعلقہ اندراجات نکالتا ہے، پھر کتاب کے اکاؤنٹنگ انداز میں انہیں ترتیب دیتا ہے اور جواب دیتا ہے، یہ بتاتے ہوئے کہ جواب کس سیکشن اور کس اندراج سے آیا ہے۔ اگر نہیں مل سکتا، تو وہ ایسا ہی کہتا ہے — وہ اعداد نہیں بناتا۔ انسٹالیشن کے لیے [اس ڈائریکٹری کا README](skills/life-decision-guide/README.md) دیکھیں۔

ہر مشورہ اس طرح نظر آتا ہے:

```markdown
### 5. گھر کا معمولی نمک کم سوڈیم نمک (پوٹاشیم نمک) سے بدل دیں
- لاگت: ایک تھیلی عام نمک سے کچھ یوآن مہنگی ہے۔ خریدتے وقت بدل لیں — اضافی وقت نہیں۔ ذائقہ تقریباً وہی رہتا ہے۔
- آسان الفاظ میں: 20,000 افراد کے بے ترتیب trial میں، جن لوگوں نے گھر کا نمک کم سوڈیم نمک سے بدل دیا، ان کی پانچ سال کے اندر موت کا امکان تقریباً 12% کم تھا، اور فالج تقریباً 14% کم۔ یہ بے ترتیب دو گروپ موازنے سے آیا ہے، مشاہداتی ٹریکنگ سے زیادہ قابلِ اعتماد۔
- فائدہ: ایک بے ترتیب trial چین کے دیہی علاقے میں 20,995 شرکاء کے ساتھ کیا گیا، جن میں سے سبھی کو要么 فالج ہوا تھا یا 60 سال سے زیادہ کے ہائی بلڈ پریشر مریض تھے۔ 4.74 سال تک پیچھا کیا گیا۔ نتیجہ: کم سوڈیم نمک والے گروپ کا موت کا خطرہ عام نمک والے گروپ کے مقابلے میں تقریباً 12% کم تھا (RR 0.88)۔ فالج تقریباً 14% کم تھا (RR 0.86)۔ بڑے کاردیو ویسکیولر واقعات تقریباً 13% کم تھے (RR 0.87)۔
- ثبوت کا درجہ: A
- ماخذ: Neal B et al. (2021). Effect of Salt Substitution on Cardiovascular Events and Death. NEJM. https://doi.org/10.1056/NEJMoa2105675
- نوٹ: متنازعہ۔ Trial کے شرکاء اعلیٰ خطرے والے بزرگ تھے؛ صحت مند نوجوانوں کو بدلنے سے بہت کم فائدہ ملتا ہے۔ جنہیں گردے کی کمی ہے، یا پوٹاشیم بچانے والی ادویات لے رہے ہیں، وہ بدلنے سے پہلے ڈاکٹر سے مشورہ کریں۔
```

## خود چلائیں

زیادہ تر لوگوں کو ڈپلائے کرنے کی ضرورت نہیں: [آن لائن تلاش صفحہ](https://humair-m.github.io/HowToLiveBetter-en/ur/) تیار ہے؛ آف لائن کے لیے، [آف لائن سنگل فائل HTML](https://github.com/eternity4719/HowToLiveBetter/releases/download/epub-latest/HowToLiveBetter.html) ڈاؤن لوڈ کریں اور ڈبل کلک کریں۔

اگر واقعی اپنی مشین یا سرور پر چلانا چاہتے ہیں:

```bash
git clone https://github.com/eternity4719/HowToLiveBetter.git
cd HowToLiveBetter
python -m http.server 8000
```

پھر براؤزر میں `http://localhost:8000/` کھولیں۔ تلاش صفحہ خالصتاً اسٹیٹک ہے — `README.md` اور `book/` اس کا ڈیٹا ہے؛ کوئی بیک اینڈ نہیں، کوئی ڈیٹا بیس نہیں، کوئی انحصار نہیں۔ پورے ڈائریکٹری کو کسی بھی اسٹیٹک سرور (Nginx، GitHub Pages، آبجیکٹ اسٹوریج) پر ڈال دیں اور یہ ویسے ہی کام کرے گا۔ نوٹ: `index.html` کو http کے ذریعے کھولا جانا چاہیے؛ مقامی فائل کو براہ راست ڈبل کلک کرنا خالی ہوگا — براؤزرز ویب پیجز کو مقامی فائلیں پڑھنے کی اجازت نہیں دیتے۔ اس منظرنامے کے لیے، اوپر کا آف لائن سنگل فائل نسخہ استعمال کریں۔

تین ای بک فارمیٹس خود بنانے کے لیے (عام طور پر غیر ضروری — ریلیز میں موجود خود بخود بنائے جاتے ہیں):

```bash
cd tools/epub && npm ci && npm run build   # EPUB
node tools/offline/build.mjs               # آف لائن سنگل فائل HTML
node tools/pdf/build.mjs                   # PDF، مزید pandoc ≥ 3.1 اور typst ≥ 0.13 کی ضرورت
```

## چار وسائل

یہ کتاب صرف آپ کو زیادہ عمر برقرار رکھنے میں مدد کرنے کے بارے میں نہیں ہے۔ کل چار چیزیں ہیں:

- **عمر**: زیادہ دیر جئیں، قابلِ روک تھام وجوہات سے کم موت
- **وقت اور توانائی**: زندہ گھنٹے صفر واپسی والی باتوں پر خرچ نہ کریں؛ روزانہ کی توجہ اور جسمانی طاقت کم ضائع ہو
- **پیسہ**: کم ضائع پیسہ خرچ کریں؛ پیسہ وہاں رکھیں جہاں واپسی یقینی ہو
- **ذاتی آزادی**: کسی سرخ لائن کو نہ جاننے کے باعث حراست یا حراستی مرکز میں نہ پھنسیں

ہر مشورہ دو سوالات کا جواب دیتا ہے: اس کی لاگت کیا ہے (پیسہ / وقت / توانائی / ارادہ)، اور کیا واپس ملتا ہے (کل اموات میں تبدیلی / مخصوص موت کے اسباب میں کمی / وقت اور توانائی بچت / پیسہ بچت / تحفظ اور ذاتی آزادی)۔ اندراجات لاگت-اثر کے لحاظ سے ترتیب دیے جاتے ہیں، نہ کہ زمرے کے لحاظ سے: چیزیں جو تقریباً کچھ نہیں لاگت آتیں اور بڑے فائدے دینے والی ہیں وہ پہلے آتی ہیں۔

**فائدے اس پر منحصر ہیں کہ کس پر پڑتے ہیں۔** "اس فائدے کا مستقبل میں آپ تک واپس آنے کی توقع" کے لحاظ سے اعلیٰ سے کم تک: ① **خود آپ**؛ ② **شریکِ حیات اور فوری خاندان** (والدین، بچے، دادا دادی، پوتے پوتی)؛ ③ **دوست، ساتھی، اور دیگر رشتہ دار** — باہمی تعلقات، دی گئی مدد واپس آ سکتی ہے؛ ④ **اجنبی** — سب سے نیچا درجہ، مگر صفر نہیں: واپسی کا امکان کم، اور آپ ان کی شخصیت نہیں جانتے، اس کے علاوہ بلیک میل، جھوٹے الزام، یا انتقام کا خطرہ۔ مختلف درجات یکجا نہیں کیے جاتے؛ جب درجہ ④ کے بارے میں لکھا جاتا ہے، تو فائدے اور خطرات دونوں ایک ساتھ درج کیے جاتے ہیں۔

ابتدائی مدد سیکشن کو اس طرح پڑھیں: چین میں 38,227 ہسپتال سے باہر دل کے رکنے کے واقعات میں سے 79.2% گھر پر ہوئے — سینے کی دباؤ سیکھنا سب سے پہلے اپنے ہی خاندان کو دبانے کے لیے ہے۔ "جب کوئی ڈوبتا ہوا دیکھیں تو خود پانی میں مت اتریں" یا "جب لڑائی ہوتی دیکھیں تو جسمانی مداخلت مت کریں" جیسے اصول خود حفاظت کے اصول ہیں، آپ کو تماشائی سے دوسرا زخمی بننے سے روکتے ہیں۔ اجنبی کے لیے ہاتھ آگے بڑھانا آپ کا اپنا حساب کتاب ہے؛ اندراجات قانونی معافیت، خود حفاظت کے اقدامات، اور خطرے کی سطح واضح طور پر بیان کرتے ہیں — وہ اسے آپ کے لیے لازمی کام کے طور پر نہیں لکھتے۔

اموات کے اعداد، وقت/توانائی کے اعداد، پیسے کے اعداد، اور قانونی نتائج ہر ایک الگ الگ شمار کیے جاتے ہیں اور آپس میں تبدیل نہیں کیے جاتے۔ یہ چاروں تلاش صفحے پر "آپ کو کیا واپس ملتا ہے" کے فلٹرز سے ملتے ہیں؛ یہ آپس میں موازنہ نہیں کیے جاتے۔

## ثبوت کا درجہ بندی

ہر مشورے کا ایک ثبوت کا درجہ ہے:

| درجہ | معنی |
| --- | --- |
| A | مخصوص تصدیق اعداد ہیں، جو متعدد مطالعات کو یکجا کرنے والی میٹا اینالیسز، بڑے کوہورٹس، یا بے ترتیب کنٹرولڈ trials (RCTs) سے ماخذ ہیں۔ یہ بتا سکتے ہیں کہ کتنی کمی ہوئی (HR، RR، فیصد کمی) |
| B | ریسرچ سپورٹ ہے مگر صحیح عدد نہیں دے سکتا؛ یا صرف چھوٹے نمونے / واحد مطالعہ سے سپورٹ |
| C | مصنف کا اپنا تجربہ، یا عام طور پر قبول شدہ عمل، براہ راست ریسرچ ادب کے بغیر |

631 اندراجات میں سے: 421 درجہ A ہیں، 159 درجہ B، 51 درجہ C۔ اضافی 58 کو متنازعہ کے طور پر نشان زد کیا گیا ہے، اور 34 مقامات کو تصدیق کے لیے TODO کے طور پر نشان زد کیا گیا ہے۔ متنازعہ A/B درجے کے اندراجات کو "متنازعہ" نشان زد کیا جاتا ہے اور انسداد ثبوت درج کیا جاتا ہے۔ تمام ماخذات صرف بنیادی ادب کا حوالہ دیتے ہیں (DOI یا PubMed لنکس کے ساتھ جرنل پیپرز، یا WHO، CDC، یا قومی بیورو آف سٹیٹسٹکس جیسے سرکاری اداروں کی رپورٹیں) — ثانوی parole نہیں۔ غیر یقینی اعداد کو "تصدیق کے لیے" نشان زد کیا جاتا ہے۔

## لاگت-اثر درجات

ثبوت کا درجہ صرف اس سوال کا جواب دیتا ہے کہ "کیا یہ عدد قابلِ اعتماد ہے"، نہ کہ "کیا یہ بات کرنے کے قابل ہے"۔ اس لیے ہر اندراج میں دو اضافی ٹیگز ہوتے ہیں: فائدے کا حجم (فائدہ کتنا بڑا ہے) اور میٹرک (کونسی چیز واپس مل رہی ہے)۔ تلاش صفحہ ان دو کو تین لاگت آئٹمز کے ساتھ یکجا کر کے ایک لاگت-اثر درجہ بناتا ہے:

| جہت | قدریں | کیسے طے ہوتی ہیں |
| --- | --- | --- |
| میٹرک | عمر / پیسہ / وقت اور توانائی / ذاتی آزادی | اس پر مبنی کہ اندراج بنیادی طور پر کیا واپس ملتا ہے۔ **مختلف میٹرکس آپس میں موازنہ نہیں کیے جاتے** — "کل اموات میں 12% کمی" اور "سالانہ 500 یوآن بچت" ایک ہی پیمانے پر نہیں ہیں |
| فائدے کا حجم | بڑا / درمیان / چھوٹا | اندراج کے اپنے "فائدہ" کالم کی پیروی کرتے ہوئے، پہلے سے طے شدہ حدوں پر فٹ ہوتا ہے نہ کہ احساس سے: عمر کے لیے، فیصد کمی سے (≥20% = بڑا، 10–20% = درمیان، <10% یا صرف درمیانی نقطہ ناپا گیا = چھوٹا)؛ پیسے کے لیے، رقم سے (دس ہزار یوآن سطح = بڑا، سینکڑوں سے ہزاروں = درمیان، درجن یوآن = چھوٹا)؛ ذاتی آزادی کے لیے، نتیجے سے (مجرمانہ ذمہ داری سے بچنا = بڑا، حراست یا انتظامی سزا سے بچنا = درمیان، دیوانی تنازع سے بچنا = چھوٹا)؛ وقت اور توانائی کے لیے، بچت کی مقدار سے (روزانہ گھنٹہ سطح = بڑا، ہفتہ وار گھنٹہ سطح = درمیان، ایک بار بچت = چھوٹا) |
| لاگت-اثر | انتہائی اعلیٰ / اعلیٰ / معمولی | بڑا فائدہ + تینوں لاگتیں صفر = انتہائی اعلیٰ؛ بڑا فائدہ + کم لاگت، یا درمیان فائدہ + صفر لاگت = اعلیٰ؛ باقی = معمولی |

631 اندراجات میں سے: 108 انتہائی اعلیٰ (17%)، 289 اعلیٰ (46%)، 234 معمولی (37%)۔ درمیان درجے کا بڑا ہونا جان بوجھ کر ہے: بنیادی فائدے کا حجم صرف تین سطحیں رکھتا ہے — بڑا / درمیان / چھوٹا — اور اس سے باریک تراشنا جعلی درستگی ہوگی۔

**یہ درجہ مصنف کا اپنا فیصلہ ہے، ثبوت نہیں۔** اس کتاب کے اپنے معیارات کے تحت، یہ خود صرف C درجے کا ہے؛ یہ ثبوت کے درجے سے الگ ہے اور اس پر اثر نہیں ڈالتا۔ ایک اندراج A درجے کا ثبوت ہو سکتا ہے مگر صرف معمولی لاگت-اثر (شنگلز ویکسین کا 97.2% فعلیت ہے فیز 3 RCT میں، مگر دو خوراہیں تین سے چار ہزار یوآن ہیں اور شنگلز شاذ و نادر ہی مہلک ہوتی ہے)، یا C درجے کا ثبوت مگر انتہائی اعلیٰ لاگت-اثر (بیرون ملک جانے سے پہلے اپنے سفر کی تفصیل خاندان کو بھیجیں)۔ "معمولی" کا مطلب "نہیں کرنا چاہیے" نہیں — کتاب میں تمام اندراجات تجویز کردہ ہیں؛ معمولی درجے کا مطلب صرف یہ ہے کہ آپ کو اس لاگت کے قابل ہونے کے بارے میں سوچنا ہوگا۔
