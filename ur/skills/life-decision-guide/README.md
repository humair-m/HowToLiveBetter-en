# زندگی کے فیصلوں کی سکل (life-decision-guide)

AI اسسٹنٹ کو *ہاؤ ٹو لائیو بیٹر* (高性价比人生指南) کی روشنی میں مخصوص سوالات کے جواب دینے دیں: کیا کرنا چاہیے، کیا قابل ہے، کیسے انتخاب کریں، حادثے کے بعد پہلے کیا کریں، کون سا پیسہ مل سکتا ہے، یہ کرنا قانوناً جرم ہے یا نہیں۔

یہ صرف ایک کام کرتی ہے: **پہلے متعلقہ اندراجات کو مرکزی متن سے نکالے، پھر کتاب کے اکاؤنٹنگ انداز میں ترتیب دے کر جواب دے**، ہر ایک میں یہ بتائے کہ کس سیکشن اور کس اندراج سے آیا ہے۔ اگر نہیں ملا، تو وہ ایسا ہی کہے — وہ یادداشت سے اعداد نہیں بناتا۔

تمام قواعد [SKILL.md](SKILL.md) میں ہیں، دونوں آلات ایک ہی فائل استعمال کرتے ہیں، دو کاپیاں برقرار نہیں رکھی جاتیں۔

## Claude Code میں انسٹال کریں

اس ریپو میں Claude Code کھولیں، انسٹال کرنے کی ضرورت نہیں — `.claude/skills/life-decision-guide/` پہلے ہی ان قواعد کی طرف اشارہ کرتا ہے۔

کسی بھی ڈائریکٹری میں استعمال کرنے کے لیے، ذاتی skill ڈائریکٹری میں کاپی کریں:

```bash
mkdir -p ~/.claude/skills/life-decision-guide && curl -fsSL -o ~/.claude/skills/life-decision-guide/SKILL.md "https://raw.githubusercontent.com/eternity4719/HowToLiveBetter/main/skills/life-decision-guide/SKILL.md"
```

اس کے بعد براہ راست پوچھیں "روزانہ دو گھنٹے کا کمیوٹ قابل ہے" یا "دوست نے ضامن بننے کو کہا، دستخط کروں؟" تو یہ trigger ہو جائے گی؛ یا واضح طور پر کہیں "life-decision-guide سے جواب دیں"۔

## Codex میں انسٹال کریں

اس ریپو میں Codex کھولیں، انسٹال کرنے کی ضرورت نہیں — روٹ کا `AGENTS.md` پہلے ہی اس کی نشاندہی کرتا ہے۔

کسی بھی ڈائریکٹری میں استعمال کرنے کے لیے، Codex کے custom prompts ڈائریکٹری میں ڈالیں، اس کے بعد `/life-decision-guide` سے بل کریں:

```bash
mkdir -p ~/.codex/prompts && curl -fsSL -o ~/.codex/prompts/life-decision-guide.md "https://raw.githubusercontent.com/eternity4719/HowToLiveBetter/main/skills/life-decision-guide/SKILL.md"
```

ہر سیشن میں خود بخود فعال ہونے کے لیے بغیر ہر بار slash کمانڈ ٹائپ کیے، یہ لائن `~/.codex/AGENTS.md` میں شامل کریں:

```markdown
جب زندگی کے فیصلوں کے سوالات کا جواب دیں (کیا کرنا چاہیے، کیا قابل ہے، کیسے انتخاب کریں، کیا مل سکتا ہے، قانوناً جرم ہے یا نہیں)، تو ~/.codex/prompts/life-decision-guide.md کے مطابق عمل کریں۔
```

## مرکزی متن کہاں سے آتا ہے

مقامی طور پر ریپو موجود ہے تو مقامی `book/` پڑھیں؛ نہیں ہے تو ابھی لائیں:

```bash
git clone --depth 1 https://github.com/eternity4719/HowToLiveBetter.git "${TMPDIR:-/tmp}/hltb"
```

پوری کتاب 1.3 MB ہے، shallow clone چند سیکنڈ میں۔ نیٹ ورک نہ مل سکے تو ایمانداری سے کہیں کہ نہیں مل سکتا، متن کا بدل نہیں دیں۔

## تبدیلیوں کا علم

SKILL.md میں کوئی بھی فہرست یا عدد نہیں رکھی گئی جو متن کے ساتھ drift ہو: سیکشنز کی فہرست README کی "یہ کتاب کس سوال کا جواب دینا چاہتی ہے" ٹیبل سے پڑھیں، لاگت-اثر درجے کا الگورتھم `index.html` میں `COST_W` اور `e.ratio` دو لائنوں سے پڑھیں۔ اس لیے سیکشنز کا اضافہ/حذف یا درجے کے قواعد بدلنے پر اس ڈائریکٹری کو چھونا نہیں پڑتا۔
