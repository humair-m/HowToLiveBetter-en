# AGENTS.md

This repository contains the main text of *How To Live Better* (高性价比人生指南).

- **Editing this book** (adding/removing entries, revising text, modifying tool scripts): all rules are in [CLAUDE.md](CLAUDE.md); everything there applies. Read it in full before doing any work. The file is called CLAUDE.md for historical reasons only — its contents have nothing to do with any specific tool.
- **Using this book to answer questions** (someone asks whether to do something, whether it's worth it, how to choose, what to do first when something happens, what money can be claimed, whether something is illegal): follow [skills/life-decision-guide/SKILL.md](skills/life-decision-guide/SKILL.md) — look up relevant entries first, then answer, citing which section and which entry each answer comes from. For instructions on installing the skill in another directory, see [skills/life-decision-guide/README.md](skills/life-decision-guide/README.md).
